### 01. AI 업무 이메일 자동화 에이전트

**졸업 프로젝트 | 서비스 기획 참여 · 백엔드 개발**

업무 이메일의 유형을 분류하고 해당 유형에 맞는 답장 초안을 제안하는 AI 기반 서비스입니다.

**주요 기여**

- 사용자 가입부터 Gmail 연결, 온보딩까지의 흐름을 검토하고 중복된 로그인 과정의 개선을 제안·구현

- Users 도메인 및 Google 서비스 연동 API 설계·구현
- 사용자·관리자 권한 분리 및 관리자 기능 개발
- Kubernetes·RabbitMQ 기반 AI 학습 Job 관리 기능 구현

**기술:** Java, Spring Boot, Google OAuth, JWT, RabbitMQ, Kubernetes

**Repositories:** [Backend Server](https://github.com/GachonCapstone4/Backend_Server) · [Admin Server](https://github.com/GachonCapstone4/Admin_Server)

### 02. 업무 이메일 분류 체계 검증 및 기준 개선

**개인 후속 프로젝트 | 데이터 검토 · 분류 기준 개선**

졸업 프로젝트에서 직접 기획했던 업무 유형 분류표를 다시 검토한 프로젝트입니다.

AI로 생성한 합성 이메일 52건을 직접 분류하며 기존 기준의 모호함을 발견하고, 판단 근거와 수정 이유를 기록했습니다.

**주요 기여**

- 제목이나 업무 주제가 아닌 현재 본문의 행위와 요구를 중심으로 분류 기준 재검토
- 기존 7개 도메인·30개 유형을 6개 전문 도메인·26개 전문 유형과 공통 4유형으로 재구성
- 유형별 포함·제외 기준, 판단 순서, 4가지 보류 사유 정의
- 분류 가이드 v1.0 작성 및 미해결 경계와 검증 한계 기록

**결과:** 분류 기준과 판단 절차를 문서화한 가이드 v1.0 완성

모델 성능이나 실제 서비스 정확도 개선은 검증하지 않았습니다.

**Repository:** [https://github.com/mandu12345/email-classification-guideline](https://github.com/mandu12345/email-classification-guideline)
